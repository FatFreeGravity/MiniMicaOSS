# Security policy

MiniMica is a local desktop starter and intentionally contains no telemetry, network client, updater, installer, or privileged service.

If you find a security issue in the template's native interop, manifest, packaging guidance, or generated application behavior, report it privately to the repository maintainer rather than opening a public issue with exploit details.

Downstream applications are responsible for the security of features they add, including WebView2 content, authentication, downloads, installers, IPC, auto-update, and elevated operations.
